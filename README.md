# smart-irrigation-tinyml (Amirhossein Mohammadi)
# سامانه آبیاری هوشمند با رزبری‌پای پیکو (TinyML)

این پروژه یک سیستم هوشمند برای تشخیص نیاز آبی گیاه است که تصمیم‌گیری را مستقیماً روی برد Raspberry Pi Pico W و بدون نیاز به اینترنت انجام می‌دهد.

## فایل‌های پروژه

* **`final_code.py`**: برنامه اصلی سیستم؛ خواندن اطلاعات سنسورها (دما، رطوبت هوا و رطوبت خاک)، تصمیم‌گیری هوشمند، فعال کردن هشدارها (چراغ‌های LED و بازر) و ارسال اطلاعات به داشبورد اینترنتی (ThingsBoard).
* **`tree_model.py`**: مدل سبک یادگیری ماشین (درخت تصمیم)؛ این کد منطق تشخیص وضعیت گیاه را با حجم بسیار کم و سرعت بالا روی حافظه میکروکنترلر اجرا می‌کند.
* **`*.json`**: تنظیمات داشبورد و ساختار بسته‌های داده ارسالی به سرور.

## روش اجرا

۱. برد رزبری‌پای پیکو را به کامپیوتر وصل کرده و برنامه **Thonny** را باز کنید.
۲. فایل‌های `final_code.py` و `tree_model.py` را داخل حافظه برد کپی کنید.
۳. نام فایل `final_code.py` را به `main.py` تغییر دهید تا برنامه با وصل شدن برق، به‌صورت خودکار اجرا شود.
